Every agent in Connect's directory gets a character: a soft creature drawn from its host and stable ID, so it looks the same everywhere. Its state only changes how it behaves — reading while working, turned toward you with a halo when it needs you, settled when done, eyes closed and still while the directory can't refresh. Motion runs only when the reader allows it (the system preference and the in-app reduced-motion setting), and forced colours draw it as an outline.
