A ready pull-request registration may name what the next message is about (`about: { id, label, onClear }`, a finding say); `RelayProductPanel` shows it as a removable reference on the composer, says when it changes under a kept draft, and clearing it sends to the whole pull request. `useRelayProductOpen().openFrom(control)` opens Relay from a page control and returns focus there on close.
