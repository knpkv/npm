# Context Map

## Contexts

- [Jira Markdown](./CONTEXT.md) — represents Jira work items as local Markdown and reconciles changes
- [Control Center](./packages/control-center/CONTEXT.md) — connects delivery work and supports governed human-agent collaboration

## Relationships

- **Control Center → Jira Markdown**: Control Center may present Jira work tracked through the shared package collection, but it does not own Jira Markdown reconciliation language.
