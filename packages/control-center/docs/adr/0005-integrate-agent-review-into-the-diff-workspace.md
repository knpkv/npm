# Integrate agent review into the diff workspace

Agent review is presented inside one full-screen pull-request review workspace rather than on a separate report page. The code diff remains the primary center surface, Review Suggestions render inline at their anchors, a compact left rail filters files and severities, and a collapsible right rail contains the Review Thread and live agent activity. A minimal top summary shows the derived Review State, suggestion counts, reviewed head, and review action. File-level and whole-change suggestions also appear in a compact overview above the diff, keeping bird's-eye status and actionable code context in one place. Full review has no arbitrary suggestion-count cap: results stream and paginate, individual fields remain size-bounded, and the Review Budget limits execution. Commands, reviewed files, and validation progress stream in the agent rail, but a suggestion appears inline only after schema and evidence validation; speculative cards never flicker into the diff. The large `Review PR` action opens a compact preflight popup that always shows the exact head, selected Review Agent Profile, Review Budget, and network status before starting; advanced options remain collapsed.
