# Own review conversation history in Control Center

Control Center owns one durable Review Thread per pull request rather than relying on Codex or Claude CLI session persistence. Each review, re-review, or revalidation is recorded as an immutable Exploratory Review Run against one exact pull-request revision and executes in a fresh Review Sandbox. Every run records its explicit Review Agent Profile; the local default may be overridden at launch, but providers never fall back silently. The single Local Operator converses with review agents in the thread; connected-service collaborators are displayed as context rather than modeled as additional Control Center users. A run receives a bounded Review Context Snapshot rather than the complete thread and command history, with full history available through explicit lookup tools. The thread preserves messages, suggestions, notes, resolutions, and run history across changing pull-request heads while preventing hidden provider, container, or unbounded transcript state from affecting later assessments.
