# Isolate agent review in an ephemeral writable sandbox

An Exploratory Review Run receives a writable project checkout inside an ephemeral, unprivileged Docker Review Sandbox created from a trusted, locally selected Review Runner image pinned by digest. It adapts the existing CodeCommit sandbox's host-side authenticated clone and lifecycle infrastructure rather than inventing a second checkout stack. A Review Checkout Broker fetches and verifies the exact base and head commits with the connected profile, strips authenticated remotes and credential configuration, copies the checkout into an isolated writable Docker volume, and deletes host staging data. The sandbox receives no host checkout bind, exposed port, AWS credential, or provider-configured arbitrary host mount. A pull request cannot alter the image evaluating it; the Local Operator configures runner changes, budget defaults, Review Agent Profiles, and network policy. Within that fixed boundary the agent runs commands autonomously without per-command approval; its activity is observable and the run is cancellable. The host checkout, Docker socket, and credentials are never exposed, and changes created in the sandbox are discarded rather than propagated automatically. Tests that require privileged or nested containers are skipped and recorded as limitations. Outbound network access is disabled by default; a run may receive an explicit, auditable allowlist of unauthenticated endpoints for integration testing, while the AI orchestrator operates outside the sandbox. Tests that require secrets are likewise skipped. A Full review has a visible 20-minute default budget, may receive one explicit extension, and returns a structured partial result when the budget is exhausted. Control Center does not serialize or cap independent runs globally; capacity failures remain explicit. On process restart, Control Center reattaches to labeled live review containers; a run whose execution no longer exists is marked interrupted with partial evidence and can only be restarted as a new immutable run. Both the staging checkout and sandbox volume are destroyed after the run. This gives the review agent full project-level capability while keeping its only durable output limited to structured Review Suggestions, Review Notes, and Review Evidence.
